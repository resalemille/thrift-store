# お取り寄せ・仕入れ代行

- `/order/`: 個人向けのお取り寄せ（オーダー）。このページだけ、ヘッダーの店名を「お取り寄せのResale Mille」に切り替える。タイトルとフッターは共通の店舗名を保つ。
- `/sourcing/`: 副業・個人事業主・法人向け仕入れ代行。オークションの悩み、4つの強み、指定の利用者の声、3コースを掲載する。
- 共通メニューのお取り寄せリンク、フッターとページ内の対象切り替えからアクセスできる。
- 問い合わせ・リクエストおよび各コースの詳細は、暫定的に既存の `/contact/` へ案内する。独立した送信フォームは設けない。既存フォームの送信機能は準備中。

表示は `src/components/OrderPage.astro`、強み・事業者の口コミ・コースは `src/data/order.ts` で管理する。個人向けの相談例写真は既存の取扱品目画像を使い、在庫・入荷の保証ではないことを明記する。個人向けのお客様の声は参考画像をもとにした仮の内容で、公開用の確認済み原稿が届いたら差し替える。事業者向けの声はIssue #49の原稿をもとに掲載する。

個人向けにはオークションの悩み・リスクや事業者用コースを表示しない。内部リンクと画像には `link()` を使用し、PRプレビューの公開パスにも対応する。
