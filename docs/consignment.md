# 委託販売ページ

- 公開パスは `/consignment/`。共通ヘッダーとフッターからアクセスする。
- Issue #32に基づき、名称を「委託販売」に統一。スマート委託の名称・専用説明・背景のSMART文字は表示しない。
- ヒーロー・強み・カテゴリの背景はトップと同じく画面の横幅いっぱいに表示する。カード群・比較表・FAQは中央の読みやすい幅に収める。
- 買取トップと同じ明るい黒・ゴールド・アイボリーの構成で、強み3点と対象3カテゴリ（腕時計、ブランド品〈バッグ・財布・小物〉、ジュエリー）を案内する。
- 強みは「業界唯一、売れる最高値を追求」「業界唯一、販売額も手数料も明確に」「業界最安値、手数料は1%から」。最高値での成約保証とはしない。
- 比較表の手数料・販売価格はIssue指定の原稿を使用する。評価記号と「※現金決済の場合」の注記は既存のまま維持する。「撮影時のみお預かり・ご自宅で保管」はユーザー確認に基づいて維持し、店舗での継続保管を前提に変更しない。
- 流れのお預かり方法は郵送とし、スマート委託固有の返却日数・現物確認時の郵送説明は削除する。成約後の発送説明は維持する。
- 冒頭は買取トップと同じ背景写真・ヒーロー構成に置き換え、ボタンは「無料でWeb査定・ご相談」の1つだけにする。利用の流れと下部相談パネルの電話・LINE・メール、共通ヘッダー・フッター、買取トップは維持する。問い合わせフォームの送信機能は引き続き準備中。
- 時計画像はIssue添付の指定写真から黒背景を除去した `public/images/consignment/watch-cutout.png` を下部の相談パネルだけで使用する。元画像: https://github.com/user-attachments/assets/85fdf634-d8e0-4e43-9ac8-67be12a73892
- FAQはJavaScript不要の `details` / `summary`。委託停止・送料など、Issueで確定していない回答は引き続き個別案内とする。
- 内部リンク・画像は `link()` を通し、本番とPRプレビューのbaseに対応する。狭い画面はカードを縦並びにし、比較表はキーボード操作可能な横スクロールにする。

## 検証

`npm test` は型検査・ビルド、本文・比較表・CTA・FAQ・素材の検証、本番と複数base配下のリンク検証を含む。画面ではPC・モバイルの配置、時計の透過、比較表とFAQを確認する。
