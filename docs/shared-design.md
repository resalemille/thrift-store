# 共通デザインの使い方

ページを追加・変更するときは、`src/components/` の共通部品を優先して使います。表示内容はページや `src/data/` で管理し、幅・余白・文字色などの共通ルールはコンポーネント側で変更します。

- `ContentContainer`: 標準の横幅と左右余白、上下余白。既定は一覧向けの `wide`、文章や会社情報には `width="reading"` を指定します。`as="article"` / `as="div"` でHTMLの役割を保てます。独自のグリッドや背景が必要な場合は内外の要素で構成します。
- `FaqItem`: `question` と `answer` を指定します。FAQページは既定のリスト表示、トップページは `variant="card"`。初期展開には `open` を指定し、標準のdetails/summaryによるキーボード操作を保ちます。
- `InfoRow`: `dl` 内に配置する項目行。`label` が見出し、本文はスロットに渡します。リンク・複数段落も利用できます。列間を広げる場合は `spacious` を指定します。
- `PageHero` / `SectionTitle`: ページ見出しとセクション見出し。
- `CaseCard` / `StoreCard` / `CategoryLink`: 実績・店舗・品目の一覧。

独自の構図を持つトップページや委託販売ページの専用セクションは、標準コンテナに無理に合わせず、用途に応じて既存デザインを維持します。同じ構造が再登場するときに共通化を検討します。

## スマホでの表示

760px以下では、トップのサービス案内を項目・補足とも中央揃えにします。委託販売の冒頭は内容に合わせた高さにし、理由カードの外側余白をトップと同じ28px・22pxに揃えます。比較表は列幅を確保した1600px以上の表を横スクロールして閲覧します。文章は折り返して全文を表示し、スクロール領域のキーボード操作を維持します。これらの調整はPC幅には適用しません。
